# Gaarp

# The goal of Gaarp
Gaarp is an investment research platform with an emphesis on creating balanced portfolios based on fundimental analysis 

# What is Gaarp
Gaarp stimulates a virtual portfolio removing the risk of capital loss while tracking the performance the portfolio as if the assets had been bought with tools and features to acess its fundimentals

# Target audienece 
Gaarp is being targeted for the SMF (Student managed fund) where students research, create and manage a portfolio over the course of the acedemic year and is presented infront of judges and industry experts in Dublin

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run build:static`    | Build prerendered pages for the S3/CloudFront deployment |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
